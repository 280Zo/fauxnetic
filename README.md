# Fauxnetic

Fauxnetic is a free Android app that shows how little it takes to copy a voice. Record a minute of
someone reading aloud (with their permission), type a line, and hear it in their voice. Voice-cloning
scams work less well when more people know how easy this is.

- **Everything runs on the phone.** Recordings, voices and lines never leave it. No account, ads or
  tracking. The only network use is downloading the voice models once, each checked against a pinned
  SHA-256.
- **Short-lived by design.** Voices and lines are deleted after 24 hours (or 1 hour).
- **Marked as synthetic.** Every line carries an inaudible watermark, and the app labels lines as
  synthetic.
- **Consent first.** A voice is built only from someone reading a passage aloud, or from a file with
  their spoken consent.

[Privacy policy](https://280zo.github.io/fauxnetic/privacy.html)

## How it works

Speech is generated by [Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS) 0.6B (voice cloning from a
short reference recording), run on the phone's CPU through
[CrispASR](https://github.com/CrispStrobe/CrispASR) (a ggml port). VoxCPM 2 and Pocket TTS are
optional extra models. Whisper (base and tiny) transcribes recordings on the phone. The voice engine
runs in its own Android process so a line can be stopped at once.

Fauxnetic carries one small patch to CrispASR (`app/native/patches/`): a per-frame hook that lets
the app stop a Qwen line that stays silent instead of speaking (a known Qwen3-TTS failure where the
model never ends a line).

## Building

Everything lives under `tools/` in the repo, so nothing is installed system-wide. You need:

- Flutter 3.50.0 at `tools/flutter`
- Android SDK at `tools/android-sdk`, with NDK r30 at `tools/android-ndk-r30` (also linked as
  `tools/android-sdk/ndk/30.0.16248370`)
- JDK 21 at `tools/jdk-21`
- CrispASR at commit `9ddae4590d427f27e0ca04694864eed66bcb530e` in `third_party/CrispASR`
  (or set `CRISPASR_SRC`)

Then:

```sh
app/native/build_crispasr_android.sh   # builds libcrispasr.so with the patch into jniLibs
cd app
tool/flutter.sh test                   # unit and widget tests
tool/flutter.sh build apk --release --target-platform android-arm64
```

The app is arm64 only. It is tuned for phones with at least 6 GB of memory; on a Galaxy A54 a short
line takes 30-45 s.
